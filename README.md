# Aligned

A mobile-responsive couples compatibility MVP focused on match reflection across Western astrology, Chinese astrology, and numerology.

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite.

## Validate

```bash
npm test
npm run build
npm run lint
```

## Privacy

Names and birth details are processed entirely in the browser. The MVP does not send or store them, require an account, use API keys, or connect to external services.

## Human setup still required

- Choose and configure a deployment provider if public hosting is needed.
- Add analytics, authentication, persistence, or sharing only after selecting an explicit privacy approach.
- Review all astrological and numerology copy with a subject-matter/editorial reviewer before commercial use.
- Replace the placeholder system score model with a documented product methodology if it is intended to do more than entertainment/reflection.

## Disclaimer

This experience is for entertainment and reflection, not scientific prediction or relationship advice.
